# microme — বহুমুখী তথ্যকোষ

## "AI-কে জিজ্ঞাসা করুন" (✨) সেটআপ

এই ফিচারটি Google-এর **Gemini API ফ্রি টিয়ার** ব্যবহার করে (ক্রেডিট কার্ড লাগে না)।

1. https://aistudio.google.com/apikey এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন
2. **Create API key** চাপুন, key-টি কপি করুন (`AIza...` দিয়ে শুরু হবে)
3. Vercel প্রজেক্টে যান → **Settings → Environment Variables**
4. নাম: `GEMINI_API_KEY`, মান: আপনার কপি করা key — সেভ করুন
5. প্রজেক্ট **Redeploy** করুন

Key ছাড়া অ্যাপ ক্র্যাশ করবে না — শুধু AI প্যানেলে একটি সেটআপ-মেসেজ দেখাবে।

ফ্রি টিয়ার লিমিট (মডেল: `gemini-2.5-flash`): প্রতি মিনিটে ~১০টি ও প্রতিদিন ~২৫০টি অনুরোধ। লিমিট শেষ হলে ব্যবহারকারীকে একটি ভদ্র মেসেজ দেখানো হবে, এরর নয়।

## ক্লাউড সিঙ্ক (Supabase) সেটআপ

`supabase_setup.sql` চালিয়ে টেবিল তৈরি করুন, তারপর Vercel-এ `SUPABASE_URL` ও `SUPABASE_ANON_KEY` যোগ করুন। কনফিগার না থাকলে অ্যাপ লোকাল মোডে চলবে।
